# Phase 1 Progress Report

## تم

- استيراد المستودع وإنشاء فرع `feature/souq-derb` والحفاظ على تاريخه.
- تدقيق البنية والكود وSupabase وAndroid والاختبارات.
- تغيير الهوية وApplication ID واسم Android وOAuth redirect.
- ضبط العربية كلغة أساسية وRTL والوضع الفاتح، وإضافة منسقات مصرية.
- إنشاء شعار أصلي مؤقت وربطه بإعدادات splash والlauncher icon.
- إضافة مخطط سوق متعدد المتاجر تراكمياً، مع مناطق وأقسام seed قابلة للتعديل.
- إضافة أدوار وحالات حساب ومتاجر ومناطق خدمة وخيارات منتجات واشتراكات وتقييمات ومخزون.
- إضافة RLS أولية وعزل ملكية التاجر.
- إضافة Checkout ذري موثوق السعر والمخزون، idempotency، snapshots، وقواعد انتقال حالة.
- إضافة repository للمناطق والمتاجر وSecure Checkout وقواعد domain واختباراتها.

## غير مكتمل بعد

- واجهات تسجيل التاجر ولوحة التاجر والإدارة وكل صفحات رحلة العميل الجديدة.
- ترحيل cart/orders القديمة بالكامل إلى الكيانات الجديدة.
- Storage buckets والسياسات بعد تحديد حدود الصورة المطلوبة.
- اختبار migrations على Supabase محلي/بعيد وتشغيل Advisors.
- FCM، وهو اختياري ولا يمنع الإشعارات الداخلية.
- APK/AAB؛ نُزّل Flutter stable لكن تشغيله حُظر عندما حاولت الأداة الوصول تلقائيًا إلى cloud metadata endpoint في بيئة العمل.

## نتائج التحقق الحالية

- `flutter pub get`: لم يكتمل — تشغيل Flutter حُظر بسبب محاولة وصول تلقائية إلى cloud metadata endpoint.
- `flutter analyze`: لم يُشغّل بعد هذا الحظر.
- `flutter test`: لم يُشغّل بعد هذا الحظر.
- APK: لم يُنشأ بسبب توقف أداة Flutter قبل مرحلة البناء.

لا تُعتبر المرحلة مكتملة وفق معايير الطلب حتى تنتهي البنود السابقة وتنجح أوامر البناء والاختبارات فعليًا.
